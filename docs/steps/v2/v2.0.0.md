## FASE 0: CI/CD y Semantic Versioning (v2.0.0-alpha)

### Objetivo

Automatizar el proceso de versionado y releases usando conventional commits y GitHub Actions.

### Archivos a Crear

```
.github/
├── workflows/
│   ├── release.yml        # Auto-release en push a main
│   └── ci.yml             # Lint/typecheck en PRs
.commitlintrc.json         # Config conventional commits
.husky/
└── commit-msg             # Hook para validar commits
CHANGELOG.md               # Auto-generado
```

### Dependencias Nuevas

```json
{
  "devDependencies": {
    "semantic-release": "^23.0.0",
    "@semantic-release/changelog": "^6.0.3",
    "@semantic-release/git": "^10.0.1",
    "commitlint": "^18.6.0",
    "@commitlint/config-conventional": "^18.6.0",
    "husky": "^9.0.0"
  }
}
```

### Tareas

| # | Tarea | Descripcion |
|---|-------|-------------|
| 0.1 | Instalar dependencias | semantic-release, commitlint, husky |
| 0.2 | Crear workflow release.yml | Auto-release en push a main |
| 0.3 | Crear workflow ci.yml | Lint/typecheck en PRs |
| 0.4 | Configurar commitlint | Validar conventional commits |
| 0.5 | Configurar husky | Hook commit-msg |
| 0.6 | Sincronizar version | package.json con tags de Git |

### Configuracion release.yml

```yaml
name: Release
on:
  push:
    branches: [main]
jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npx semantic-release
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### Configuracion ci.yml

```yaml
name: CI
on:
  pull_request:
    branches: [main]
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci
      - run: npm run lint
      - run: npm run typecheck
```

## FASE 2: Paginas Legales (v2.0.0)

### Objetivo

Crear las paginas legales requeridas, con jurisdiccion Venezuela.

### Archivos a Crear

```
app/(legal)/
├── layout.tsx                 # Layout minimalista
├── privacy/page.tsx           # Politica de privacidad
├── terms/page.tsx             # Terminos y condiciones
└── confidentiality/page.tsx   # Confidencialidad
```

### Contenido de las Paginas

#### Politica de Privacidad

- Datos recopilados (email, datos financieros encriptados)
- Uso de los datos (solo para el servicio)
- Seguridad (E2E encryption, bcrypt para passwords)
- Derechos del usuario (acceso, eliminacion, exportacion)
- Jurisdiccion: Venezuela

#### Terminos y Condiciones

- Descripcion del servicio
- Uso aceptable
- Responsabilidades del usuario
- Limitaciones de responsabilidad
- Modificaciones al servicio
- Jurisdiccion: Venezuela

#### Confidencialidad

- Explicacion de encriptacion E2E
- Responsabilidad del usuario sobre su clave
- Recuperacion de cuenta
- Datos que el servidor puede ver
